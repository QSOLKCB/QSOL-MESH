# QSOL-MESH Evidence Contract

MESH evidence describes execution; it does not redefine workload truth.

Receipts distinguish requested configuration, observed topology/constraints, calibration candidates, selected plan, effective CPU workers/devices, memory placements, transfer bytes where measurable, setup/calibration/execution/verification timing, oracle result, reduction/commit identity, source/runtime identity, and claim boundary.

A receipt must not imply universal speedup from one host, correctness from speed, physical truth from a checksum, uniform physical memory from unified addressing, requested topology as effective topology without observation, or model-name performance authority.

Machine schema: `machine/evidence-contract.v1.json`.
